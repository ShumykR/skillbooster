# SkillBooster

Інтерактивний шлях для Python-бекендера: від FastAPI до DevOps та AI-інженерії.
13 етапів, безкоштовні ресурси і 171 практичне завдань з production-кейсами.

## Як запустити

Збірка не потрібна. Відкрий `index.html` у браузері (працює навіть з `file://`).
Прогрес зберігається в `localStorage` браузера; в «Налаштуваннях» є експорт та імпорт JSON. Поняття етапу мають два рівні: «розумію» (галочка або пройдений тест самоперевірки 🧠) і «довів» (зроблено пов'язане завдання).

Для зручності можна підняти локальний сервер:

```
python -m http.server 8000
```

## Структура

| Файл | Призначення |
|---|---|
| `index.html`, `styles.css`, `app.js` | Сайт (чистий HTML/CSS/JS, без залежностей) |
| `data.js` | Етапи, ресурси, завдання. **Генерується** скриптом із `docs/tasks-catalog.md` |
| `tasks/` | Завдання з автоперевіркою (pytest). Див. `tasks/README.md` |
| `ci/tasks.yml` | CI: кожне завдання окремим джобом. Щоб увімкнути, скопіюй у `.github/workflows/tasks.yml` |
| `tools/gen_data.py` | `python tools/gen_data.py` перегенерує `data.js` після змін у каталозі завдань |
| `docs/free-resources.md` | Підбірка безкоштовних ресурсів з умовами та лімітами |
| `docs/tasks-catalog.md` | Каталог завдань (джерело правди для завдань) |
| `docs/platform-design.md` | Опис задуму платформи |

Описи етапів, поняття і ресурси редагуються у `tools/gen_data.py` (список `STAGES`); зв'язки «поняття → завдання» у `tools/quiz_data.py`, питання самоперевірки в `tools/quizzes/` (модуль на етап).

## Налаштування AI-проксі

Завдання з позначкою 🤖 читають три змінні середовища:

```
LLM_BASE_URL=https://your-proxy.example/v1
LLM_API_KEY=...
LLM_MODEL=...
```

Ключ не зберігається на сайті. Тримай його в `.env` (додай у `.gitignore`) та в GitHub Secrets.
Автоперевірка в CI має використовувати мок-LLM, щоб не залежати від ключа.

## Дорожня карта

1. **MVP (готово):** карта шляху, ресурси, завдання, трекінг прогресу.
2. **Автоперевірка (83 завдання готові):** `cd tasks && python check.py --open`: сайт відкриється й запропонує позначити пройдені завдання як «перевірено тестами». Далі додаємо ще завдання за каталогом.
3. Наскрізний проєкт: AI-бекенд, який росте з етапами.
4. За потреби: вхід через GitHub, спільний прогрес, AI-підказки.
