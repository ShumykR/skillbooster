# Завдання з автоперевіркою

Кожна папка `tNN_назва` це окреме завдання з реального production-кейсу:

```
t02_async_dashboard/
├── README.md        умова, критерії, підказки
├── solution.py      стартовий код, який потрібно дописати або виправити
└── test_solution.py тести, які і є автоперевіркою
```

Номер `NN` збігається з номером завдання в каталозі та на сайті.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows;  source .venv/bin/activate на Linux/macOS
pip install -r requirements.txt

python check.py                 # усі завдання
python check.py t02             # одне завдання
python check.py --open          # і відкрити сайт, щоб відмітити пройдені
python -m pytest t02_async_dashboard   # або напряму pytest
```

`check.py` створює `skillbooster-sync.html`: відкрий його (або запускай з `--open`), і сайт запропонує позначити пройдені завдання як «✅ перевірено тестами». Якщо сайт відкриваєш не з диска, а за адресою (GitHub Pages, `http.server`), задай `SKILLBOOSTER_URL`. Запасний шлях: імпорт `skillbooster-progress.json` через «Налаштування → Імпорт JSON».

## Правила

- Редагуй лише `solution.py` (і додаткові файли, якщо завдання це дозволяє). Тести не змінюй.
- Спершу всі тести червоні, і це нормально: ти їх «позеленюєш».
- Готових розвʼязків тут немає навмисно. Застряг: прочитай підказки в README завдання, потім питай AI-асистента, але проси **пояснення**, а не готовий код.

## CI

Воркфлоу лежить у `ci/tasks.yml`; скопіюй його в `.github/workflows/tasks.yml` у корені репозиторію. Він запускає кожне завдання окремим джобом. Завдання, яке ти ще не розвʼязав, червоне, і так має бути.
