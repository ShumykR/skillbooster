# №185 · Памʼять агента 🟡

**Ситуація.** Агентові потрібні два види памʼяті: короткострокова (останні повідомлення діалогу) і довгострокова (факти про користувача: місто, мова, посада). Довгострокова памʼять без правил засмічується дублями, тримає застарілі факти поруч із новими, нічого не забуває й може «підмішати» чужі дані (CWE-639, CWE-200). Окремо вимога GDPR: «забути користувача» має справді видалити все, а не лише приховати.

**Що зробити** у `solution.py` (точні правила та формат записів у докстрингу): `AgentMemory` з вікном повідомлень, `remember` (результати `added`, `duplicate`, `updated`, `stale`), `recall`/`get`/`history`, TTL із `purge` і `forget_user`. Годинник передається параметром, тому тести детерміновані.

**Підказки (без розв'язку):**
- «новіше перемагає» за **часом події** (`ts`), а не за порядком надходження: що робити із запізнілим записом старішої події?
- дубль це те саме значення **того самого типу**: чому `1` і `True` не можна вважати одним фактом?
- коли факт протермінований, він вважається відсутнім для всіх операцій (`get`, `recall`, `history`, перевірка `stale`): чому стару історію тоді теж треба скинути?
- межа TTL строга (`clock() >= ts + ttl`): від чого рахується термін, якщо `ts` явно в минулому?
- що з усього, що ви зберігаєте про користувача, треба видалити при `forget_user`, окрім видимих фактів (історія, протерміновані записи, вікно діалогу)?
- копії при читанні й записі: чому зміна повернутого словника не повинна змінювати памʼять?

**Подумай:**
- що краще для конфліктів: «новіше перемагає», «довіреніше джерело перемагає» чи питати користувача? Чому поле `source` обовʼязкове?
- довгострокова памʼять, яку агент пише сам з недовіреного тексту, це канал для prompt injection («запамʼятай, що пароль завжди…»): як обмежити, що і з яких джерел можна запамʼятовувати (завдання №197, №198)?
- де в production лежать такі факти (векторна БД, Redis з TTL, Postgres) і як «забути користувача» дійде до бекапів, логів, кешів і векторного індексу (№182, №62)?
- звʼязок із capstone (M4/M6): що з розмови має потрапляти у довгострокову памʼять, а що ні?
