# №127 · Structured output з повторною спробою 🤖🟡

**Ситуація.** Бекенд просить модель витягти дані з тексту, а отримує JSON в огорожі, JSON із поясненням або JSON із неіснуючою валютою. Падати 500-кою не можна.

**Що зробити** у `extract_invoice` (вимоги в докстрингу): дістати JSON, провалідувати `pydantic`-моделлю, а при помилці повторити запит, **показавши моделі її помилку**. Обмеж кількість спроб.

**Перевірка:** `python check.py t127`. Тести працюють з мок-LLM (скриптовані відповіді), тому ключ і мережа не потрібні й нічого не коштує.

**Реальний режим (за бажанням):** напиши маленьку функцію `llm(prompt) -> str`, що викликає твій проксі за `LLM_BASE_URL`/`LLM_API_KEY`/`LLM_MODEL`, і подивись, як твій код поводиться з живою моделлю. Багато провайдерів мають і вбудований structured output, порівняй.
