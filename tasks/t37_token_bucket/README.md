# №37 · Rate limiter (token bucket) 🟡

**Ситуація.** API-клієнт може заспамити ендпоінт. Потрібен ліміт, який дозволяє короткі сплески, але тримає середню швидкість.

**Що зробити** у `solution.py`:
- відро на кожен ключ: `capacity` токенів, поповнення `refill_per_sec` (дробове поповнення теж працює);
- `allow` списує токени, відхилений запит нічого не списує;
- `retry_after` повертає час очікування, для `cost > capacity` це `inf`;
- безпечно для кількох потоків (тест запускає 50 потоків).

**Перевірка:** `python check.py t37`
