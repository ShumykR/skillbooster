# №59 · Підписані URL та доступ до файлів (IDOR) 🔴

**Ситуація.** Користувач відкриває `GET /download?file=1042` і бачить свій рахунок. Змінює число на `1043` і бачить чужий. Це IDOR (Insecure Direct Object Reference, CWE-639): сервер перевіряє, що ти *автентифікований*, але не перевіряє, що файл *твій*. Це перше в списку OWASP API Security (BOLA). Друга частина проблеми: посилання на файл поширюють у чатах і логах, і воно має давати доступ не вічно й не кому завгодно.

**Що зробити** у `solution.py`:
1. `sign_download` / `verify_download`: підписане посилання з терміном дії, прив'язане до файлу *і до користувача*;
2. `FileService`: `download_link` видає посилання лише тому, хто має право на файл (власник, ті, з ким поділились, адмін); `open` перевіряє підпис і право **ще раз**.

Усі формати, порядок перевірок і тексти помилок у докстрингу файлу.

**Підказки (без розв'язку):**
- підпис має покривати *все*, що впливає на рішення (файл, користувач, термін): якщо чогось не підписано, це можна підмінити;
- підпис перевіряється *до* перевірки терміну, а порівняння робиться через `hmac.compare_digest`;
- «не твій файл» і «файлу немає» мають бути для клієнта однаковими (одна помилка, одне повідомлення), інакше можна перебором id дізнатись, які файли існують;
- у посиланні лежить ідентифікатор файлу, а не шлях: шлях на диску береться лише зі сховища на сервері.

**Подумай (тести цього не покривають):**
- чому перевірка права ще раз при відкритті обов'язкова, якщо посилання вже підписане? Що станеться з «доступом, скасованим після видачі», без неї?
- послідовні числові id відкривають перебір; UUID це лише додатковий шар, а не заміна перевірки доступу: авторизація на *об'єкт* потрібна завжди (завдання №52, ABAC);
- у S3 те саме робить presigned URL: підписане посилання на конкретний ключ з терміном, а ліміти на розмір і тип задають умовами (див. №13, №145);
- чого не вміє ця схема: відкликання *одного* посилання до кінця терміну (потрібен список відкликаних або короткий TTL) і одноразовість посилання (потрібен лічильник).

**Перевірка:** `python check.py t59`. Спершу тести червоні (заглушки кидають `NotImplementedError`). Лише стандартна бібліотека.
