# №41 · Перевірка підпису вебхука 🟡

**Ситуація.** Платіжний провайдер шле вебхуки. Будь-хто може підробити такий запит, якщо не перевіряти підпис.

**Що зробити** у `verify_webhook`:
- розібрати заголовок `t=...,v1=...` (можливо кілька `v1` при ротації ключів);
- перевірити HMAC-SHA256 від `"{t}." + payload` у **постійний час** (`hmac.compare_digest`);
- відхилити запити, чий `t` відрізняється від `now` більше ніж на `tolerance` секунд (у минуле й у майбутнє);
- відхилити повторну доставку того ж підпису (`seen`), але **лише після** успішної перевірки, інакше атакуючий засмітить `seen`;
- будь-яке сміття в заголовку це `InvalidSignature`, а не `ValueError`.

**Перевірка:** `python check.py t41`

**Памʼятай:** підписувати треба **сирі байти** тіла, а не перекодований JSON.
