# №66 · Мережа: де саме ламається `curl -v` 🟡

**Ситуація.** «Сайт не відкривається» може означати чотири принципово різні речі: домен не резолвиться (DNS), порт закритий або відкинутий файрволом (TCP), сертифікат прострочений чи не для цього імені (TLS) або сервер відповів помилкою (HTTP). Лікування в кожного етапу своє, а `curl -v` показує всі етапи підряд, якщо вміти його читати. Тут ти пишеш «читача»: функцію, що за виводом `curl -v` ставить діагноз. Так ти запам'ятаєш, що саме за чим іде.

**Що зробити** у `solution.py`: `diagnose_curl(output)` повертає `{"stage", "cause", "detail"}`. Таблиця кодів curl, причин і полів `detail` у докстрингу файлу. Фікстури в тесті це справжні за формою виводи curl для кожного випадку: прочитай їх, це корисно саме по собі.

**Підказки (без розв'язку):**
- головний сигнал це останній рядок `curl: (N) ...`; без нього діагноз ставимо за останнім `< HTTP/...`;
- код 28 (timeout) нічого не каже про етап сам по собі, тому етап визначається тим, що вже встигло з'явитись у виводі: чи був надісланий запит (`> GET`), чи почався TLS handshake;
- `curl -L` показує кілька відповідей підряд: рахуй 3xx *перед* останньою;
- `re.findall` з якорями `^` і прапором `re.M` зручніший за розбір по рядках; не забудь `\r\n`.

**Подумай (тести цього не покривають), і перевір руками:**
- DNS: `dig +short example.com`, `dig @1.1.1.1 example.com` (порівняй свій резолвер із публічним), `getent hosts`; `/etc/resolv.conf`, `search`-домени й чому `host` у Kubernetes резолвиться через `cluster.local`;
- TCP: `ss -ltnp` (хто слухає порт), `nc -vz host port`, `tcpdump -nn port 443` (SYN без SYN-ACK означає, що пакет відкинуто; RST означає, що порт закритий); чому «refused» і «timeout» лікуються по-різному;
- TLS: `openssl s_client -connect host:443 -servername host -showcerts` (SNI!), `openssl x509 -noout -dates -subject -ext subjectAltName`; цепочка довіри й чому «unable to get local issuer» часто означає, що сервер не віддав проміжний сертифікат;
- HTTP: `curl -v --http1.1`, `-H 'Host: ...'` до IP напряму, `--resolve host:443:IP`, `-w '%{time_namelookup} %{time_connect} %{time_appconnect} %{time_starttransfer}\n'` для розбивки часу по етапах.

**Перевірка:** `python check.py t66`. Спершу тести червоні (заглушка кидає `NotImplementedError`). Лише стандартна бібліотека, мережі немає.
