# №36 · Cache stampede 🔴

**Ситуація.** Популярний ключ протух, і 1000 запитів одночасно йдуть у базу. База падає.

**Що зробити** у `solution.py` реалізувати `SingleFlightCache.get`:
- кеш із TTL (годинник передається ззовні, щоб тести були детермінованими);
- при одночасних запитах на один ключ `loader` викликається **один раз**, решта чекають на той самий результат;
- різні ключі не блокують один одного;
- якщо `loader` впав, помилку отримують усі, хто чекав, а в кеш вона **не** потрапляє;
- скасування одного з очікувачів не має ламати інших.

**Перевірка:** `python check.py t36`

**Підказки:** зберігай «поточне завантаження» як `asyncio.Future`/`Task` у словнику; подумай про `asyncio.shield`.
