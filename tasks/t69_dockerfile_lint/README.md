# №69 · Лінтер Dockerfile 🟡

**Ситуація.** Образ важить 1,2 ГБ, працює від root, а кожна зміна коду перевстановлює всі залежності. hadolint ловить такі речі, але корисно один раз зрозуміти, *що* саме він перевіряє, і написати мінімальну версію сам.

**Що зробити** у `lint_dockerfile` (правила DF001–DF007 у докстрингу): розібрати Dockerfile та повернути відсортований список ідентифікаторів порушених правил. Підказки по парсингу:
- інструкції нечутливі до регістру (`run`, `RUN`);
- рядок може продовжуватись через `\`, а коментарі можуть стояти навіть усередині такого продовження;
- `FROM` може мати `--platform=...` та `AS назва`; `FROM builder` посилається на попередню стадію, а не на образ.

**Перевірка:** `python check.py t69`. Docker не потрібен.

**Далі (поза тестами):** постав справжній [hadolint](https://github.com/hadolint/hadolint) і порівняй його висновки зі своїми на тих самих файлах. Виміряй `docker image ls` до і після multi-stage та `.dockerignore`.
