# №2 · Async під навантаженням 🟡

**Ситуація.** Дашборд збирає дані з кількох внутрішніх сервісів. Зараз вони викликаються по черзі, а один повільний сервіс вішає всю сторінку.

**Що зробити** у `solution.py`:
- викликати сервіси паралельно, але не більше `max_concurrency` одночасно;
- дати кожному сервісу `timeout` секунд (час очікування в черзі не рахується);
- збій або таймаут одного сервісу не ламає відповідь: він потрапляє в `errors`;
- повільний сервіс після таймауту має бути скасований.

**Перевірка:** `python check.py t02` або `python -m pytest tasks/t02_async_dashboard`.

**Підказки без розв'язку:** `asyncio.gather`, `asyncio.Semaphore`, `asyncio.wait_for`. Подумай, де саме має стояти `wait_for` відносно семафора.
