# №136 · MCP-сервер: tools і resources над вашим API 🟡 🤖

**Ситуація.** Model Context Protocol це спосіб один раз описати інструменти й дані вашого сервісу так, щоб будь-який MCP-клієнт (Claude Desktop, IDE, ваш агент) міг їх використати без індивідуальної інтеграції. Під капотом це JSON-RPC 2.0 з кількома методами: `initialize`, `tools/list`, `tools/call`, `resources/list`, `resources/read`. Справжній SDK сховає деталі, але щоб його правильно застосовувати (і відлагоджувати), корисно раз зробити ядро самому.

**Що зробити** у `solution.py` (точні коди помилок і формати результатів у докстрингу): клас `McpServer`:
- обробка JSON-RPC: помилки парсингу й невалідні запити, notification без відповіді, batch;
- `initialize` із `capabilities` за наявними tools/resources; решта методів до ініціалізації відхиляються;
- `tools/list` та `tools/call` із перевіркою аргументів за `inputSchema` (відсутні, невідомі, типи); **помилка самого інструмента це не протокольна помилка**, а результат з `isError: true`, який бачить модель;
- `resources/list` та `resources/read`.

**Підказки (без розв'язку):**
- повідомлення без ключа `id` це notification: відповідати на нього не можна, навіть помилкою; `id: 0` не відсутній `id`;
- помилки протоколу (`-32600`, `-32601`, `-32602`) відрізняй від помилок виконання інструмента;
- аргументи від моделі не довіряй: невідомі поля відхиляй, типи перевіряй (`bool` не є числом);
- текстовий результат складай так, щоб кирилиця залишалась читабельною (`ensure_ascii=False`).

**Подумай:**
- які операції вашого API *не* варто віддавати як tools без авторизації за користувачем (№137, №98) і чому MCP-сервер на stdio має ті самі права, що й процес;
- коли дані краще віддавати як resource (довідка, документ, лише читання), а коли як tool (дія з параметрами);
- як це виглядає з офіційним Python SDK (`FastMCP`) і як протестувати сервер MCP-клієнтом у pytest;
- як описувати інструменти (`description`, приклади), щоб модель обирала правильний.

**Перевірка:** `python check.py t136`. Лише стандартна бібліотека. Далі: загорни ядро у stdio-транспорт (читання рядків JSON зі stdin) або перенеси на `FastMCP` і підключи до MCP-клієнта.
