# №61 · Логи без PII 🟡

**Ситуація.** У логах знайшли email-и, номери карток і токени. Це порушення GDPR/PCI DSS і готовий витік.

**Що зробити** у `mask_pii` (правила в докстрингу): email, картки з перевіркою **алгоритму Луна** (щоб не псувати довгі id), `Bearer`-токени, значення секретних ключів у `key=value` та JSON. Функція ідемпотентна.

**Перевірка:** `python check.py t61`

**У production:** маскування роблять у `logging.Filter`/процесорі structlog **до** запису; найкраще взагалі не логувати чутливі поля.
