# №43 · Retry з backoff і circuit breaker 🟡

**Ситуація.** Сторонній API інколи падає. Наївні повтори в циклі лише добивають його (retry storm), а ваші воркери зависають.

**Що зробити** у `solution.py`:
1. `retry`: експоненційна затримка з обмеженням `max_delay` та jitter, повтор лише для вказаних винятків, після вичерпання спроб піднімається останній виняток.
2. `CircuitBreaker`: стани `closed → open → half_open`, лічильник невдач **підряд**, один пробний виклик у `half_open`.

**Перевірка:** `python check.py t43`

**Чому jitter:** без нього тисячі клієнтів повторюють запит в один і той самий момент і знову кладуть сервіс.
