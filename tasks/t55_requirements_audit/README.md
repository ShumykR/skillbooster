# №55 · Аудит залежностей 🟡

**Ситуація.** `pip install flask` сьогодні й через рік ставить різні версії. А якщо в залежності знайшли вразливість, ніхто не помітить, доки не вдарить. Для захисту ланцюга постачання потрібні три речі: точні версії, хеші пакетів і постійна перевірка на відомі вразливості ([pip-audit](https://github.com/pypa/pip-audit), Dependabot/Renovate).

**Що зробити** у `audit_requirements` (правила у докстрингу): розібрати `requirements.txt` у форматі `pip-compile --generate-hashes` і знайти відхилення. База вразливостей приходить параметром `advisories`, мережа не потрібна.

**Підказки (без розв'язку):**
- `"4.2.9" < "4.2.11"` як рядки хибне, а як числа вірне;
- хеші в `pip-compile` стоять на окремих рядках після `\`;
- маркер `; python_version < "3.9"` не є частиною версії.

**Перевірка:** `python check.py t55`.

**Далі:** згенеруй lock-файл (`uv pip compile --generate-hashes` або `pip-compile --generate-hashes`), встанови з `--require-hashes` і запусти справжній `pip-audit -r requirements.txt`.
