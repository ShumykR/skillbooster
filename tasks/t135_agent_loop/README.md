# №135 · Цикл агента з запобіжниками 🤖🔴

**Ситуація.** Агент без обмежень входить у нескінченний цикл викликів і палить бюджет, а одна помилка інструмента валить увесь запит.

**Що зробити** у `run_agent` (повні правила в докстрингу): цикл «модель → інструмент → спостереження», помилки інструментів як **спостереження для моделі**, обрізання довгих відповідей, виявлення повторюваних викликів і жорсткий ліміт кроків.

**Перевірка:** `python check.py t135`. `llm` у тестах скриптований, ключ не потрібен.

**У реальному світі додай:** бюджет токенів/грошей на запит, таймаут на кожен інструмент, журнал усіх викликів (трасування), підтвердження користувача для небезпечних дій (див. №137).
