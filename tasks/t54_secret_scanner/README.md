# №54 · Сканер секретів 🟡

**Ситуація.** Ключ AWS потрапив у коміт, і через 3 хвилини боти вже майнили на ньому. Видалити його наступним комітом мало: він лишився в історії git. Тому секрети шукають автоматично, до пушу (pre-commit) і в CI: [gitleaks](https://github.com/gitleaks/gitleaks), [trufflehog](https://github.com/trufflesecurity/trufflehog).

**Що зробити** у `scan_secrets` (правила у докстрингу): знайти секрети у файлах і не здіймати хибних тривог на заглушки та читання з оточення.

**Подумай:**
- чим більше правил, тим більше false positives; саме тому існує механізм винятків (`nosecrets`) і allowlist;
- знайдений ключ треба **відкликати** (rotate), а не лише видалити з коду; після цього чистять історію (`git filter-repo`);
- не клади справжні ключі у власні тести: у цих тестах значення згенеровані.

**Перевірка:** `python check.py t54`.

**Далі:** підключи gitleaks як pre-commit хук і крок у GitHub Actions у власному репозиторії.
