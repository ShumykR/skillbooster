# №51 · Перевірка JWT 🟡

**Ситуація.** Більшість зламів JWT це не злам криптографії, а пропущені перевірки: `alg: none`, підміна алгоритму, прострочений токен, чужа аудиторія.

**Що зробити** у `verify` (правила в докстрингу): розібрати токен, перевірити алгоритм, підпис у постійний час, `exp`, `nbf`, `aud`. Будь-яке сміття на вході це `InvalidToken`, а не `KeyError`/`binascii.Error`.

**Перевірка:** `python check.py t51`

**Памʼятай:** тут ми пишемо руками, щоб вивчити пастки. У реальному коді бери PyJWT і **завжди** передавай явний список дозволених алгоритмів.
